# TIA HMI Skill

A reusable agent skill for Siemens SIMATIC HMI and WinCC engineering in TIA Portal. The skill routes tasks across Basic, Comfort, Advanced, Professional, and Unified while requiring version- and device-specific verification.

## Contents

- `SKILL.md`: trigger metadata, core workflow, and engineering boundaries.
- `references/`: platform selection, task workflows, and source policy.
- `evals/evals.json`: representative prompts for checking skill coverage.

Use the repository root as the skill folder so relative links in `SKILL.md` resolve. Keep Siemens manuals in their licensed location; this repository contains references to the manuals, not copies of them.
